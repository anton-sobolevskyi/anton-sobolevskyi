## Featured Project: SprintLine

**Project Management Application**  
Angular 22 · NestJS · Prisma · PostgreSQL · NgRx · Playwright

SprintLine is a full-stack project management application designed for small teams. It enables users to create and manage projects, organize work on a Kanban board, assign tasks, collaborate through comments, and attach files — all within a clean, modern interface.

The application covers the complete product flow: authentication (sign up, sign in, password reset, email verification), a personal dashboard with assigned work and upcoming deadlines, project membership with role-based access (Owner, Admin, Member), task lifecycle management with status and priority, and real collaboration features.

Built with a production-oriented approach, SprintLine demonstrates end-to-end ownership of a modern web product. It includes secure JWT authentication with refresh token rotation, role-based access control, soft deletes, file storage via S3-compatible services, type-safe API communication through OpenAPI-generated contracts, and a polished user experience with support for light/dark themes and a command palette.
